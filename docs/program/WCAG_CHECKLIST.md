# WCAG critical-flow audit checklist

## Flows to audit first

1. Home create/join meeting  
2. Room controls (mute, leave, chat, knock admit)  
3. Classroom login + assignment submit  
4. Org create/invite  

## Checks

- [ ] Keyboard only  
- [ ] Visible focus  
- [ ] Labels / `aria-*` on icon buttons  
- [ ] Contrast ≥ 4.5:1 body text  
- [ ] Live regions for knock/toast  

Remediate blockers before marketing “accessible classrooms.”
